# 🤖 WhatsApp Bot

A modular WhatsApp bot starter project with:

- WhatsApp command system
- Interactive menu
- Media-tool placeholders
- AI-tool placeholder
- TikTok promotion planning
- TikTok API integration structure
- Express health server
- Environment-variable configuration

## Requirements

- Node.js 18+
- WhatsApp account
- Git
- GitHub repository
